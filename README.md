EasyBag致力于在Godot打造优秀且易上手的框架与编辑器，旨在设计师与程序员的高效协作。欢迎使用，我们正在改进。
下载压缩包并解压，随后放置于res://vcder/文件夹之下(0.1a版本请放在res://下)，运行EasyBag文件夹中的EasyBag场景即可使用编辑器，在此之前请确保您安装了必要的vcder依赖。

EasyBag aims to build an excellent and easy-to-use framework and editor for Godot, enabling efficient collaboration between designers and programmers. Welcome to use it—we are continuously making improvements.
Download the archive and extract it, then place it in the res://vcder/ folder (for version 0.1a, please place it directly under res://). Run the EasyBag scene inside the EasyBag folder to launch the editor. Before doing so, please ensure you have installed the required vcder dependencies.
