#EasyBag
##简介
  EasyBag是一款Godot中的库存与物品系统框架，通过可视化编辑器实现无代码编辑和自动生成物品
配置类，随后在gds代码中使用EasyBag系列的类进行玩法开发，可轻松实现设计师与工程师的巧妙合作。

##快速开始
  先将下载取得EasyBag文件夹，将文件夹放置于res://vcder/之下。
  在运行EB编辑器前请确保安装了DataCourier和ControlPlus(与EasyBag相似的按照方法)。
  运行EasyBag文件夹下的EasyBag场景启动EB编辑器(不同于常见的Godot编辑器插件,由于EB编辑器
需要占用大量资源所有需要作为场景运行而不是常驻在Godot编辑器面板中)
  进入编辑器后点击上方工具栏的 file-new 打开创建文件面板
  选择Codex并且选择好地址进行创建
